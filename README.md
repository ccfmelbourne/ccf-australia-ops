# CCF Australia Operations Platform

This repository is the engineering foundation for the CCF Australia Operations Platform. It defines the architecture, documentation, and governance needed to build a modular monolith for Finance and future operational modules.

## Repository contents

- `.ai/` — AI and project context guidance.
- `docs/product/` — product and stakeholder documentation.
- `docs/architecture/` — architecture decisions and system design.
- `docs/development/` — development standards and contribution guidance.
- `adr/` — architectural decision records.
- `specs/` — domain and feature specifications.
- `.github/` — workflows, issue templates, and repository automation.

## Getting started

1. Read the charter in `.ai/PROJECT.md`.
2. Review the architecture overview in `docs/architecture/README.md`.
3. Review development guidance in `docs/development/README.md`.
4. Read the ADR and specs usage guides in `adr/README.md` and `specs/README.md`.

## Project charter

The approved project charter is captured in `.ai/PROJECT.md` and serves as the source of truth for purpose, scope, stakeholders, and principles.

## Notes

- This repository is intentionally foundation-first. It is not an application implementation.
- Unknown decisions are marked with TODO.
